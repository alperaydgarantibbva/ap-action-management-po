# Epic'ler

Epic = tek sprinte sığmayan, birden fazla story'ye bölünen büyük iş parçası.

Dosya adı: `E-NN-kisa-baslik.md`

Şablon: [`../../_sablonlar/epic.md`](../../_sablonlar/epic.md)

## Epic mi story mi?

| | Story | Epic |
|---|---|---|
| Süre | Birkaç gün | Birkaç sprint |
| Kabul kriteri | Somut, test edilebilir | Genel hedef |
| Tek başına değer üretir mi | Evet | Bölünmeden hayır |

**Pratik kural:** Bir işi bir sprintte bitiremeyeceğinizi düşünüyorsanız o bir epic'tir; bölün.
