# Toplantı Notları

Dosya adı: `YYYY-AA-GG-toplanti-adi.md`

Örnek: `2026-08-20-paydas-kickoff.md`

Şablon: [`../_sablonlar/toplanti-notu.md`](../_sablonlar/toplanti-notu.md)

## Hangi toplantılar buraya yazılır?

- Paydaş görüşmeleri
- Karar toplantıları
- Kickoff, çeyrek planlama
- Ekip dışı teknik görüşmeler

Sprint törenleri (refinement, review, planlama) `02-sprintler/sprint-NN/` altına yazılır — sprint bağlamında aranması daha kolay.

## Not tutma kuralı

Toplantı sırasında iki şeyi mutlaka yakalayın: **verilen kararlar** ve **kimin ne yapacağı**. Geri kalanı sonra hatırlanabilir; bu ikisi hatırlanmaz.
